## What this branch changes

### feat(skills): 新增 rebase 到 master 的本地需求笔记工作流

Adds a trailing rule to root `AGENTS.md` requiring one note per local requirement or fix under `.agents/skills/dsh-rebase-onto-master/notes/`, keeps the matching code replayable as source and tests only, resolves the rebase base from the newest `release(dsh): <version>` commit on `origin/master` with `--empty=drop --onto "$base" "$fork"`, classifies a note absent from that base but present on `origin/master` as `post-release` instead of replaying it, and writes a tracked `migrations/` document from `## Summarize the branch`, `## Check machine compatibility`, and `## Write the migration document` before rewriting history.

Machine-facing: none.

### feat(open-in-app): Windows 直接启动真实可执行文件并复用窗口

On Windows, `packages/host/open-in-app` dereferences `.cmd`/`.bat` shims to the real executable, falls back to the PATH `code` command when registry and known-path locators miss, and passes `--new-window` instead of `--reuse-window` to VS Code so opening a second workspace stops evicting the first.

Paths: `packages/host/open-in-app/src/catalog.ts`, `src/resolver.ts`, `tests/resolver.spec.ts`. Machine-facing: none.

### fix(fs-local): 重试 ReplaceFileW 瞬时共享锁与 1175 删除冲突

`packages/fs/fs-local` retries `ReplaceFileW` on Win32 errors 32, 33, and 1175 with bounded backoff, maps exhaustion to `EBUSY`, lets the write abort signal cancel a retry wait, and keeps publication on `ReplaceFileW` instead of falling back to rename.

Paths: `packages/fs/fs-local/src/win32.ts`, `src/fsio.ts`, `tests/win32.spec.ts`, `tests/fsio.spec.ts`. Machine-facing: none.

### feat(web): 图标改为圆角光栅图标集并拆分 maskable 用途

The browser tab and installed application switch from `favicon.svg` to a raster set. `favicon.ico`, `icon-192.png`, and `icon-512.png` are rounded with alpha; `icon-maskable-192.png`, `icon-maskable-512.png`, and `apple-touch-icon.png` stay opaque so the platform mask does not cut a second shape. The manifest declares real pixel sizes and splits `purpose` into `any` and `maskable`. `apps/web/public/favicon.svg` is deleted, and `packages/host/frontend-static` gains `.png` and `.ico` MIME entries without which the icons serve as `application/octet-stream`.

Paths: `apps/web/public/*`, `apps/web/index.html`, `apps/web/tests/pwa-manifest.e2e.ts`, `packages/host/frontend-static/src/index.ts`. Machine-facing: every `apps/web/public` file is served from a fixed URL, and the deleted `favicon.svg` was still named by a script in this branch — see the finding below.

### chore(scripts): 新增 DSH Web 启动脚本与开始菜单快捷方式安装脚本

Adds `dsh-web.ps1` (runs `pnpm dsh web --no-open` from the repository root and propagates pnpm's exit code) and `install-dsh-web-shortcut.ps1` (creates the `DSH Web` Start Menu shortcut, optionally rendering a multi-size icon with ImageMagick, and refreshes an existing taskbar pin).

Machine-facing: both scripts are new, both require `pnpm` on `PATH`, and the installer still resolves its icon from `website\public\favicon.svg` after dropping the `apps\web\public\favicon.svg` entry this branch deletes.

Resolutions:

- Install ImageMagick from https://imagemagick.org, then re-run `pwsh -File install-dsh-web-shortcut.ps1 -ForceIcon`. Without it the installer still writes the shortcut and warns that it did not render a custom icon.
- `COMMANDCODE_API_KEY` is read by the MCP server from its own checkout, not from this repository: the profile row sets `cwd: 'D:\personal\commandcode-web-search-mcp'` and `bun` loads `.env` from there. Recreate `D:\personal\commandcode-web-search-mcp\.env` on a new machine; the repository root needs no `.env`.

## Finding: the deleted `favicon.svg` was still referenced

`apps/web/public/favicon.svg` is deleted by this branch, and `install-dsh-web-shortcut.ps1` listed it as an icon source. The list is filtered by `Test-Path`, so the missing entry was skipped and `website/public/favicon.svg` still supplied the icon; the installer kept working, but it named a file this branch removed. Resolved in this branch by dropping the `apps\web\public\favicon.svg` entry and narrowing the warning to `website\public`.

## Steps on another machine

1. `git pull` the branch.
2. `pnpm install` — no local commit changes `pnpm-lock.yaml`, so the checkout only has to match the lockfile the base already carries.
3. Install the toolchain: Node `^22.19 || >=24`, `pnpm@11.7.0`, PowerShell 5.1+, and `bun` for the profile's MCP row.
4. Install ImageMagick, or accept the default console icon.
5. Create `D:\personal\commandcode-web-search-mcp\.env` holding `COMMANDCODE_API_KEY`.
6. Recreate the DSH web profile. It is per-machine and cannot be pulled: `~/.dsh/profiles/web/package.json` links local checkouts by absolute path (`link:D:/personal/...`), and `cordis.patch.yml` inserts `file:///D:/personal/...` plugin entries. Rewrite those paths for the new machine, or rebuild the profile from `packages/bundle/web-app`.
7. Install the shortcut: `pwsh -File install-dsh-web-shortcut.ps1`; pass `-ForceIcon` to re-render the icon.
8. Run `pnpm --filter @deepseek-ai/dsh-fs-local test` and `pnpm --filter @deepseek-ai/dsh-host-open-in-app test`; both cover Windows-only behavior this branch changes.
9. Run `DSH_SNAPSHOT=replay pnpm run test:web` if browser output changed.
