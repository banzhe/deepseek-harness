### fix(open-in-app): VS Code 的 Windows 定位器改用 --new-window

On Windows, `packages/host/open-in-app` passes `--new-window` from the VS Code locators, so opening a second workspace focuses a window already holding that exact directory instead of loading the new directory into the last active window and evicting the project it held. The behaviour no longer depends on the deployment-invisible `window.openFoldersInNewWindow` setting.

Paths: `packages/host/open-in-app/src/catalog.ts`, `tests/resolver.spec.ts`. Machine-facing: none.

### fix(fs-local): 重试 ReplaceFileW 瞬时共享锁与 1175 删除冲突

`packages/fs/fs-local` retries `ReplaceFileW` on Win32 errors 32, 33, and 1175 after 25, 50, and 100 ms, maps exhaustion to `EBUSY`, lets the write abort signal cancel a retry wait, and keeps publication on `ReplaceFileW` instead of falling back to rename.

Paths: `packages/fs/fs-local/src/win32.ts`, `src/fsio.ts`, `tests/win32.spec.ts`, `tests/fsio.spec.ts`. Machine-facing: none.

### feat(web): 图标改为圆角光栅图标集并拆分 maskable 用途

The browser tab and installed application switch from `favicon.svg` to a raster set. `favicon.ico`, `icon-192.png`, and `icon-512.png` are rounded with alpha; `icon-maskable-192.png`, `icon-maskable-512.png`, and `apple-touch-icon.png` stay opaque so the platform mask does not cut a second shape. The manifest declares real pixel sizes and splits `purpose` into `any` and `maskable`. `apps/web/public/favicon.svg` is deleted, and `packages/host/frontend-static` gains `.png` and `.ico` MIME entries without which the icons serve as `application/octet-stream`.

Paths: `apps/web/public/*`, `apps/web/index.html`, `apps/web/tests/pwa-manifest.e2e.ts`, `apps/web/tests/clickable-links-gallery.e2e.ts`, `packages/host/frontend-static/src/index.ts`, `tests/frontend-static.spec.ts`. Machine-facing: every `apps/web/public` file is served from a fixed URL. No profile, settings, or root script still names the deleted `favicon.svg`.

The release had since replaced the single favicon with a light/dark pair selected by media queries (`favicon.svg` and `favicon-dark.svg`) and deleted the script that swapped them. The raster set replaces that mechanism, so the replay also drops `apps/web/public/favicon-dark.svg`, points `apps/web/tests/settings-chrome.e2e.ts` at the theme-independent `/favicon.ico` and `/icon-512.png`, and extends the desktop bundle allowlist in `apps/desktop/src/main.ts` from `/favicon.svg` to the six raster paths. Without that last edit the installed desktop app would 404 its own icons.

### chore(scripts): 新增 DSH Web 启动脚本与开始菜单快捷方式安装脚本

Adds `dsh-web.ps1` (runs `pnpm dsh web --no-open` from the repository root and propagates pnpm's exit code) and `install-dsh-web-shortcut.ps1` (creates the `DSH Web` Start Menu shortcut, optionally rendering a multi-size icon with ImageMagick, and refreshes an existing taskbar pin).

Machine-facing: both scripts are new. `dsh-web.ps1` requires `pnpm` and `pwsh` on `PATH`; the installer also looks for `magick`, which is optional.

### feat(ui-workspace): 折叠的工作区分组图标增加执行中状态

The sidebar session tree's Workspace (folder) header reports executing work while the group is folded. A folded group shows no session rows, so their status dots are off screen; the header's closed-folder glyph carries the same animated `ongoing` state dot as a badge on its bottom-right corner, labelled `group.running` (`有会话正在运行` / `A session is running`). `GroupNode.running` is derived in `deriveGroups` from the group's visible members and is always false while the group is expanded. The badge takes no focus; the enclosing row keeps its single toggle action.

Paths: `packages/client/ui-workspace/src/client/tree.ts`, `rows/Rows.tsx`, `rows/Rows.module.css`, `locales.ts`, `tests/tree.client.spec.ts`, `tests/rows.client.spec.tsx`. Machine-facing: none.

The release had since removed the descendant-lineage index and counts running children from each Session's subagent catalog, and it renamed the folder glyphs to `IconFolderOpenRegular` and `IconFolderCloseRegular`. The replay keeps both: the badge uses those glyph names, and `groupRunning` reads `runningChildCount` instead of the deleted index. The folded-group test builds its running child through that catalog.

## Steps on another machine

1. `git pull` the branch.
2. `pnpm install` — no local commit changes `pnpm-lock.yaml`, so the checkout only has to match the lockfile the base already carries.
3. Install the toolchain: Node `^22.19 || >=24`, `pnpm@11.7.0`, PowerShell 5.1+, and `bun` for the profile's MCP row.
4. Install ImageMagick, or accept the default console icon.
5. Create `D:\personal\commandcode-web-search-mcp\.env` holding `COMMANDCODE_API_KEY`.
6. Recreate the DSH web profile. It is per-machine and cannot be pulled: `~/.dsh/profiles/web/package.json` links local checkouts by absolute path (`link:D:/personal/...`), and `cordis.patch.yml` inserts `file:///D:/personal/...` plugin entries plus the `bun` MCP row. Rewrite those paths for the new machine, or rebuild the profile from `packages/bundle/web-app`.
7. Install the shortcut: `pwsh -File install-dsh-web-shortcut.ps1`; pass `-ForceIcon` to re-render the icon. This machine already has the `DSH Web` Start Menu shortcut, and the rebase does not move its target.
8. Run the verification commands below.
